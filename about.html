Về tôi

Tôi là sinh viên Năm 2 ngành Công nghệ thông tin. Tôi đam mê học hỏi các công nghệ web mới như HTML, CSS, JavaScript.


Định nghĩa kỹ năng

HTML5
Ngôn ngữ đánh dấu siêu văn bản dùng để dựng cấu trúc cho trang web.
CSS3
Ngôn ngữ định kiểu dùng để thiết kế giao diện và trang trí trang web.
Git
Hệ thống quản lý phiên bản mã nguồn phân tán.

Kỹ năng lập trình

  • HTML5
  • CSS3
  • Git & GitHub
  • JavaScript cơ bản

Lộ trình học tập

  1. Nắm vững nền tảng HTML5 và CSS3 cơ bản.
  2. Thực hành hoàn thiện các dự án website cá nhân.
  3. Học thêm JavaScript để làm trang web tương tác động.
